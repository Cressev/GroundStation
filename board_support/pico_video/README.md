# Pico 双目视频服务源码镜像

- `stereo_stream.py`：同步双目 JPEG 视频服务，枚举每个立体尺寸支持的离散帧率；相机关闭时原子应用尺寸、采集帧率和上传目标，发送上限可达 120 FPS。
- `native_mjpeg.py`：可控 V4L2 子进程采集原生 MJPEG，开启前读回帧率；无法确认时拒绝该通路，由服务尝试 OpenCV 并再次验证。

这两份文件与机器鱼项目 `pico_stereo/pico_stereo/` 同名源码同步，部署到 Pico 的 `/root/catkin_ws/src/pico_stereo/pico_stereo/`。部署前须确认板端当前代码、保留旧文件备份并检查相机和用户现有连接，不得覆盖未知改动；服务需按原有 `ros2 launch` 方式在适当时机重启才加载新代码。不得借此启动舵机或修改控制桥。原生录像是左右目未经校正的画面，需 PyAV；无法获得独立曝光时间戳或保证所选帧率能在任何环境下达到。

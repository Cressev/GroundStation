# 机器鱼端视频流服务部署说明

## 文件说明

1. **camera_stream_server.py** - 视频流服务器脚本
2. **camera_stream.launch** - ROS launch文件

## 部署步骤

### 1. 将文件复制到机器鱼

将以下文件复制到机器鱼 ROS 工作空间：

```bash
# 在你的电脑上（假设机器鱼IP为192.168.137.241）
scp camera_stream_server.py orangepi@192.168.137.241:~/catkin_ws/src/fish_control/scripts/
scp camera_stream.launch orangepi@192.168.137.241:~/catkin_ws/src/fish_control/launch/
```

### 2. 在机器鱼上设置权限

```bash
# SSH登录到机器鱼
ssh orangepi@192.168.137.241

# 进入脚本目录
cd ~/catkin_ws/src/fish_control/scripts/

# Win向Linux传输的文件回车符不一致，需要统一
sed -i 's/\r$//' camera_stream_server.py

# 添加执行权限
chmod +x camera_stream_server.py
```

### 3. 运行方式

#### 方式A: 使用launch文件（推荐）

```bash
roslaunch fish_control camera_stream.launch
```

#### 方式B: 直接运行脚本

```bash
cd ~/catkin_ws/src/fish_control/scripts/
python3 camera_stream_server.py
```

#### 方式C: 自定义参数运行

```bash
python3 camera_stream_server.py --port 9998 --camera 0 --width 640 --height 480 --fps 20 --quality 80
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| port | 9998 | 服务器监听端口 |
| camera | 0 | 摄像头设备索引 |
| width | 640 | 视频宽度 |
| height | 480 | 视频高度 |
| fps | 20 | 目标帧率 |
| quality | 80 | JPEG压缩质量 (1-100) |

## 故障排查

### 问题1: 无法打开摄像头

```
✗ 无法打开摄像头 0
```

**解决方案**:
- 检查摄像头是否正确连接
- 尝试其他摄像头索引: `--camera 1` 或 `--camera 2`
- 使用 `ls /dev/video*` 查看可用设备

### 问题2: 地面站无法连接

**解决方案**:
- 检查防火墙设置
- 确认端口9998未被占用: `netstat -an | grep 9998`
- 检查网络连接: `ping 192.168.137.241`

### 问题3: 帧率过低

**解决方案**:
- 降低分辨率: `--width 320 --height 240`
- 降低JPEG质量: `--quality 60`
- 检查网络带宽

## 性能优化

### 降低延迟
- 使用较低的JPEG质量 (60-70)
- 减小分辨率
- 脚本已启用TCP_NODELAY

### 提高画质
- 增加JPEG质量 (90-95)
- 增大分辨率
- 注意：会降低帧率和增加延迟

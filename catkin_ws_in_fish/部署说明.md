# 机器鱼端部署说明

## 前置准备

### 为root用户安装opencv-python
由于launch文件需要以root权限启动（访问深度传感器），而camera_stream_server需要cv2，需要为root用户安装opencv：

```bash
# 切换到root用户
sudo su

# 安装opencv-python
pip3 install opencv-python

# 验证安装
python3 -c "import cv2; print('cv2 version:', cv2.__version__)"
```

如果pip3安装失败，可以使用apt：
```bash
apt update
apt install -y python3-opencv
```

## 部署步骤

### 1. 从地面站传输文件到机器鱼
```bash
# 传输socket服务器
scp catkin_ws_in_fish/fish_control/scripts/socket_server.py orangepi@192.168.137.241:~/catkin_ws/src/fish_control/scripts/

# 传输launch文件
scp catkin_ws_in_fish/fish_control/launch/sensor_socket.launch orangepi@192.168.137.241:~/catkin_ws/src/fish_control/launch/
```

### 2. 在机器鱼端启动
```bash
# 切换到root用户（访问深度传感器需要root权限）
sudo su

# 启动所有服务（传感器+控制+摄像头）
roslaunch fish_control sensor_socket.launch
```

**一条命令启动所有服务**，包括：
- IMU传感器
- UWB定位
- 深度传感器
- Socket控制服务器（端口9999）
- 舵机控制节点
- 摄像头视频流（端口9998）
- 全局定时器

## 故障排除

### 问题1: ModuleNotFoundError: No module named 'cv2'
**原因**: root用户未安装opencv
**解决**: 按照"前置准备"中的步骤安装opencv-python

### 问题2: 深度传感器无法访问
**原因**: 需要root权限
**解决**: 确保使用`sudo su`切换到root用户后再启动launch

### 问题3: 端口被占用
**原因**: 之前的进程未正常关闭
**解决**: 
```bash
# 查找占用端口的进程
netstat -tlnp | grep 9999
# 杀死进程
kill -9 <PID>
```

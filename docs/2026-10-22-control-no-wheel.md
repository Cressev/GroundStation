# 左侧控制栏数字参数禁用滚轮调整

用户要求：滚动左侧页面时不能意外修改参数；选中输入框后仍可用上下箭头或直接编辑。
仅改电脑端数字输入事件，不改参数范围/步长、控制算法、通信协议、启停或保存逻辑。

## 日常使用与预期

1. 重开地面站以加载新代码。左侧切换键盘、深度或Xbox控制；参数处于锁定状态时原锁定仍有效。
2. 将鼠标停在任一数字输入框上滚动：数字不变，左侧页面正常上下滚动。
   即使刚刚点过这个输入框、有输入焦点，也不允许滚轮改变数字；鼠标停在数字文本上行为相同。
3. 点击输入框后，键盘↑/↓按原步长调整；输入框旁的上下按钮仍可点击；选中文字后可直接填写数字。
4. 仍按原流程点击“应用参数”“应用并保存参数”或胸鳍“设定”等按钮生效；本次不引入新的自动应用行为。

覆盖整数和浮点数字项：键盘9项；深度/PID额外9项及其键盘9项，共18项；Xbox13项，总计40个输入框。
包括频率、幅度、偏置、相位差、胸鳍脉宽、目标深度、PID增益、积分限幅、超时和Xbox死区/速度等。
非数字下拉框、其他页面的缩放/图表滚动不在本次修改范围。

## 实现与扩展约束

`ui/numeric_inputs.py`提供`NoWheelSpinBox`和`NoWheelDoubleSpinBox`，三控制器统一使用。
采用StrongFocus保留点击/Tab焦点；在输入框和内部文本控件处截获滚轮，不运行Qt默认的数值步进。
将事件转交最近的外层`QAbstractScrollArea`视口，保留角度/像素增量、滚动阶段和反向标记。
没有外层滚动区域时忽略事件。不能仅通过“未聚焦才禁滚轮”实现，否则点击后继续滑动仍会误改参数。

后续新增控制栏数字参数也应使用这两个类，不直接创建普通QSpinBox/QDoubleSpinBox。
原有参数值、格式、限幅、后缀、按钮、键盘事件过滤及锁定开关继续沿用。

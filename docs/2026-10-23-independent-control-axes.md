# 独立航向控制＋深度控制（第一版）

左侧不再在“键盘/深度/Xbox”之间三选一，而是分成两个上下排列的控制通道。
后续正式单双环计算均已移到Pico，本页保留第一版记录；最新规则见[板端定深说明](2026-10-23-pico-parallel-pid.md)。
两路都有类型下拉、启动框和自己的参数，航向当前可选键盘或Xbox，深度当前只有单闭环PID。
没有添加未实现的IMU双环选项。系统信息移到右下角，左侧控制内容整体滚动；按键说明默认折叠，可点击展开。

## 运行与操作

1. 重开地面站加载新代码。进入`src/GroundStation`，使用`conda activate agentscope`后运行`python main.py`，选择双尾双目鱼。
   两个启动框默认均未勾选，不会自动恢复运行；本次不改Pico/STM32程序，也不需要重新刷板。
2. 保持原硬件连接：电脑经现有有线网络连接Pico，Pico串口连接STM32；舵机供电/共地按原规程。
   板上仍运行原一键入口，UI连接机器鱼后两路启动框才可操作。控制功能不依赖打开摄像头或双目测距。
3. 上方“航向控制”选键盘或Xbox，未启动时参数置灰。勾选“启动航向控制”成功后才可编辑并按原按钮应用。
   键盘W/A/D等或Xbox方向/LT控制尾鳍；Xbox需要已连接手柄才可启动，启动失败参数保持置灰。
4. 下方“深度控制”选择单闭环PID，未启动时参数置灰；启动成功后直接填写并应用目标深度/增益/限幅/中位/输出方向/数据超时，无需额外解锁。
   反馈仍为`fused - zero_offset`，单位cm，水下向下为正；不使用相机测距数据作为鱼体深度反馈。
5. 确认当前保存参数与实验条件安全后勾选“启动深度控制”，按已保存参数启动。不论航向是否启用，PID都可独立启动；等待一个新的深度样本后计算，旧缓存/重复样本不重复积分。
   无新数据时保持配置中位，运行后数据超时按原策略清积分并回配置中位；默认超时0.5秒。
6. 顶部常驻文字显示尾鳍来源和胸鳍归属/PWM。这里是最终合成指令，不是舵机位置传感器反馈。

| 航向启动 | 深度启动 | 尾鳍 | 胸鳍 |
|---|---|---|---|
| 否 | 否 | 不运动 | 无周期控制，保持/安全中位 |
| 是 | 否 | 键盘或Xbox | 沿用该输入源的手动胸鳍 |
| 否 | 是 | 频率、幅度为0 | 单闭环PID |
| 是 | 是 | 键盘或Xbox | 单闭环PID独占 |

当前支持键盘＋PID、Xbox＋PID，也支持单独航向或单独深度。
PID启动时QE、胸鳍直接“设定”、Xbox Y/A/RT与“胸鳍回中”都不覆盖胸鳍，也不在后台累积偏移；
手动脉宽框/设定或回中按钮会置灰。尾鳍参数不受PID影响。

## 停止、切换与安全

- 单独取消“启动航向控制”：停尾鳍，深度PID继续运行，不清其积分/采样状态。
- 单独取消“启动深度控制”：停止PID，从最后合成的PWM交回手动，不跳回启动PID前的旧手动值。
  无航向运行时胸鳍保持该指令，直到下一次明确的控制操作或全停。
- 每一通道未启动时参数框和应用按钮置灰，启动成功后开放编辑，停止/紧停/断线后重新置灰；另一通道不受影响，未应用输入保留。深度页不再显示额外参数解锁框。
- 每一通道运行时锁自己的类型，未启动时仍可选型。航向停止后可换键盘/Xbox，不必停PID；来回切换保留各自参数输入，不多生成控制器/定时器。
- 参数和控制类型都不能被滚轮误改；数值仍可点击后用键盘上下键、按钮或直接编辑。参数应用/保存逻辑不变。
- “全部停止”：撤销两路、停止尾鳍、发送安全1500μs胸鳍值。主动断链/关闭窗口走同一安全路径；被动断链无法再发送帧，但撤销两路并停定时器，板端断链保护仍在。
- Xbox X/B或手柄断开：立即停尾，关闭航向和深度两路，保持最后合成胸鳍值；X/B短震、断连不震动，启动Xbox成功长震保持原逻辑。
  当前航向类型选中Xbox时，即使只启动深度、没有启动航向，也保留X/B和已接入手柄断开的紧停监视；不会因此启用尾鳍运动。
  紧停/断链后重连不会自动启动。先确认摇杆回中，再分别重新启动所需通道。
- 单尾版本仍为原键盘控制路径，不新增无数据源的深度控制；其系统信息也移至右下角。

## 实现边界

`ControlCoordinator`是双尾鱼唯一完整指令出口。每个来源都被标记，旧/停用来源的信号被拒绝；
尾鳍字段只取选中航向快照，胸鳍只取当前拥有者，每次创建新的完整命令，避免可变旧对象改写已发送帧。
`DepthAxisController`复用原单环PID数学、默认首次dt=0.1秒、后续实际单调时间差并限在0.001～1秒，
仅暴露深度参数页、产生胸鳍结果，不执行继承的键盘尾鳍更新。旧DepthController保留用于兼容和算法回归。
未来IMU双环可接独立深度通道，但本版没有实现。板端协议、SGBM/相机配置均未改变。

# 双目页录制按钮与统计

连接机器鱼、连接视频并开启摄像头，收到画面后，绿色“开始录制”可用。按下变为红色“停止录制”；右侧空白区域显示例如`录制中 00:02:15 · 1620帧`。不可录制时按钮是灰色，不会仅用颜色区分状态。

再次点击停止并选择MP4保存位置。停止后保留本次时长和帧数，悬停统计可看完整保存路径；下次开始清零。断线、关闭相机或退出会沿用原自动保存逻辑，计时也停止。开始后还没有新帧就停止，不生成空视频。编码器初始化/写帧异常显示“录制失败”，保留此前帧数，不继续假计时。

时长为单调时钟计算的实际经过时间，每250ms刷新；没有新画面时，时间继续而输入帧数不增加。界面上的帧数只统计提交给本地录像的处理后画面（左右目合为一帧），不是网络接收帧率或摄像头原始帧率。后台线程按15 FPS时间轴采样最新画面：输入较慢时保持上一画面，输入过快时取最新画面；停止后将输入帧数和包含补帧的编码帧数写入统计悬停提示。编码持续落后超过2秒或写入失败则显示失败并保留已有部分，不能恢复已经丢失的画面。OpenCV没有逐帧落盘回执，需要实际解码核验。点击测点的重绘不额外录帧。

按钮仍一排，统计放在同排右侧，窄屏仅工具栏横向滚动。没有修改分辨率、NPZ、采集服务或板端代码。现有运行进程不会热加载；完成你当前录制、保存后自行重开地面站即可，不需要重启Pico。

## 离线复现

操作目的：独立合成画面验证颜色、真实MP4时长及左右目尺寸，不连接机器鱼；每轮输入30帧，编码帧按真实经过时间计算；截图和JSON摘要保留在输出目录。

```powershell
cd D:\Documents\Study\codex-fish\src\GroundStation
conda activate agentscope
python -X utf8 ref/verify_stereo_recording.py --output ../../tmp/stereo-recording-manual
```

输出目录必须不存在。预期摘要中`decoded_frames`与实际时长×15相符、`decoded_shapes: [[320,240,3]]`、`start_color: #15803d`、`stop_color: #b91c1c`、`hardware_touched: false`；帧数可因运行时长变化。窗口自动关闭，MP4和截图仍留在输出目录。只有合成画面，无硬件接线要求，不调用摄像头或网络。

# Xbox 手柄控制使用说明

- 创建时间：2026-10-16 17:59
- 最近更新：2026-10-17 00:23
- 创建原因：为双尾机器鱼增加 Windows 蓝牙 Xbox 手柄连续控制，并明确首次联调的安全步骤。

## 功能边界

Xbox 输入在地面站电脑上读取，通过现有 `9999` 控制连接发送频率、摆幅、偏置、相位差和胸鳍
PWM。Pico、STM32 固件和串口协议不需要修改。当前只在启动时选择“双尾双目鱼”后显示此模式。

UI 显示的胸鳍角度是把硬件完整范围 `500–2500 μs` 线性映射到 `0–180°` 得到的指令估算值，
不是舵机位置传感器反馈。

## 按键映射

| 输入 | 行为 |
|---|---|
| 左摇杆前半圆 | 超过死区后启动游动；角度连续控制左右方向，摇杆长度不控制速度 |
| 左摇杆后半圆 | 不产生倒退，也不停止；冻结进入后半圆前一刻的尾鳍频率、摆幅、偏置和 LT 状态 |
| 左摇杆由后半圆重新进入前半圆 | 恢复方向响应；即使从最左侧绕到最右侧，尾鳍偏置也会在两个当前摆动周期内连续过渡，不会突变 |
| 左摇杆进入中心死区 | 尾鳍在两个当前摆动周期内平滑停止 |
| LT | 从“LT 松开”参数连续插值到“LT 全按”参数；变化在两个目标摆动周期内平滑完成 |
| Y | 按住时以设定速度均匀增加胸鳍 PWM，趋向上浮 |
| A | 按住时以设定速度均匀减小胸鳍 PWM，趋向下潜 |
| Y 和 A 同时按 | 两个方向抵消，胸鳍保持当前位置 |
| RT 与 Y/A 同时按 | RT 行程越大，胸鳍越接近设定的快速调节速度 |
| X 或 B | 绕过平滑过程，立即发送尾鳍频率/摆幅为零的命令，胸鳍保持当时位置；当前手柄双电机短震 250 ms 后自动停止，并关闭总控制 |

其他按键当前忽略。手柄断开与 X/B 使用相同的立即停尾和锁定关闭逻辑，但断开后无法发送震动指令。
LT/RT 是无符号 8 位模拟量，完整物理行程应在实时状态中均匀显示为 0～100%。

## UI 参数

- `LT 松开频率/摆幅`：左摇杆进入前半圆、LT 未按时的普通游动量。
- `LT 全按频率/摆幅`：LT 完全按下时的加速上限；软件要求不低于普通值。
- `最大转向量`：左摇杆到前半圆左右边界时，叠加在基础偏置上的最大绝对转向偏置。
- `基础偏置`：直游和停止时的尾鳍中心偏置。
- `相位差`：双尾关节相位差，单位 rad。
- `摇杆死区`：摇杆半径低于此值时视为回中，默认 0.15。
- `胸鳍最小值/中位/最大值`：胸鳍 PWM 的软件安全范围与回中位置。
- `胸鳍普通速度`：只按 Y/A 时的变化率，单位 `μs/s`。
- `胸鳍 RT 速度`：RT 全按且同时按 Y/A 时的变化率。

点击“应用并保存”后参数写入项目根目录的 `xbox_params.json`。点击“胸鳍回中”只改变胸鳍，
不会启动尾鳍。

## 启动步骤与预期状态

1. 在 Windows 蓝牙设置中确认 Xbox 手柄已连接，并按 Xbox 徽标键唤醒手柄。
   预期：地面站 Xbox 页面显示“手柄：已连接（编号 1）”；若显示未连接，不允许启用控制。
2. 连接机器鱼，但先不要勾选“启用控制”。选择“Xbox 控制”，检查 LT/RT 和方向百分比会随操作变化。
   预期：尾鳍不动，页面只更新输入状态。
3. 首次台架测试把普通/加速摆幅和频率调低，确认左摇杆已回中，再勾选“启用控制”。
   预期：回中状态不会启动尾鳍。
4. 缓慢向前推左摇杆。
   预期：尾鳍在两个周期内由零平滑升到普通参数，左右移动连续改变偏置。
5. 从前半圆左侧进入后半圆，保持摇杆不回中心，再沿后半圆移动到右侧并重新进入前半圆。
   预期：在整个后半圆内保持进入前一刻的尾鳍状态；重新进入右侧前半圆后，偏置用两个当前摆动周期从左侧值连续过渡到右侧值。摇杆只有回到中心死区时才平滑停止。
6. 保持左摇杆在前半圆，逐渐按下 LT。
   预期：频率和摆幅连续升高，在两个目标周期后到达相应 LT 行程的目标值。
7. 分别按住 Y、A，再配合 RT，观察胸鳍 PWM 与估算角度。
   预期：Y 均匀增加、A 均匀减小、RT 提高变化速度，松键后保持最后值。
8. 按 X 或 B。
   预期：尾鳍立即停止，不等待两个周期；手柄短震约 250 ms 后自动停止，总控制自动取消勾选。再次测试前必须让摇杆回中并重新启用。

## 安全说明

- 首次水池验证从低频率、小摆幅和较窄胸鳍范围开始。
- X/B 紧停只立即停止尾鳍，胸鳍保持最后指令，避免紧急状态下突然跳回中位；短震是本地反馈，不改变发给机器鱼的控制量。
- 关闭总控制或断开机器鱼连接仍走地面站原有通用停止链，胸鳍回到中位。
- 蓝牙休眠后即使 Windows 设置曾显示“已配对”，XInput 也可能读不到设备；先唤醒手柄再启用控制。

# 顶部跟踪及定时转弯合并实施计划

**目标：**将已有顶部相机跟踪、键盘转弯模式及定时自主控制整合到现有地面站分支，保留录像修复和本地用户参数。

**方案：**以双方共同提交 `44b03b7` 为基线进行三方合并；先校验并备份误复制的未跟踪文件，仅临时移出与合并目标字节一致的文件；解决 README 等冲突时同时保留两边内容。不修改 Pico 或 STM32 固件。

**步骤与验证：**

1. 检查当前分支、暂存区和待合并文件，备份用户未提交文件并核对哈希。
2. 对合并目标相同的误复制文件做可恢复迁移，合并 `dual-fish-stereo-Liangyu`，检查冲突和改动范围。
3. 运行无硬件的顶部跟踪、标定、键盘转弯、定时控制和现有录像回归；检查安全门闩以及传感器/深度控制的协调。不得连接实物或发送运动指令。
4. 如实记录测试结果，以中文提交并推送当前分支；保留运行时参数和无关文件，不强制推送。

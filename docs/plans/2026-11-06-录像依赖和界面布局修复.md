# 录像依赖和界面布局修复计划

**目标：**修复 qt5 启动地面站时 PyAV 缺失，取消双目按钮栏横向滚动，并让右侧系统信息靠近深度页且保留按键和快捷键行为。

**方案：**在项目隔离运行目录安装与两种 Python 3.10 ABI 匹配的 PyAV，不改用户 Conda 环境；双目操作拆成两行；隐藏原按键状态页但保留 P/C 功能，系统信息加入当前键状态。不得停止用户现有地面站、相机、机器鱼或改变控制链。

1. 备份并核对当前源码、Python 运行环境和未提交文件；验证本机项目隔离 PyAV 可被 agentscope 与 qt5 加载。
2. 编写跨环境录像依赖回归，验证真实 MP4 编码、时间戳和不依赖用户已有连接的兼容性。
3. 改造双目工具栏双行布局和右侧布局，测试单双尾、不同窗口宽高、栏收放、按键状态及 P/C 旧行为。
4. 用独立窗口/合成数据验证，不连接或中断现有业务；更新中文说明，提交并推送原分支。

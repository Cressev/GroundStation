# 双目采集帧率选择实施计划

**目标：** 按相机真实枚举为每目分辨率选择 15、30、60、120 FPS，并明确采集、发送、录像和显示帧率的区别。

**方案：** Pico 解析 MJPEG 尺寸及离散帧率，新增相机关闭时才生效的分辨率/帧率原子配置与请求确认；采集启动后读回 V4L2 帧率。地面站按板端能力置灰不可用选项，录像保持用户选择的发送上限，旧服务不能伪装为支持新协议。保留 latest-only 显示处理，说明其上限和丢帧策略。

**验证：** 能力解析、错误及幂等状态机、录制不覆盖配置、Qt 布局与控制安全回归；Pico 板端备份、隔离端口实际读回 15/30/60/120 及不支持场景，不启动测距和舵机。正式部署前比较源文件并备份，不覆盖用户改动。
